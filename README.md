👨‍💻 Sobre Mim

Sou estudante de Ciência da Computação na Universidade Estadual da Paraíba (UEPB) e desenvolvedor de software com uma formação técnica sólida em fundamentos da computação, engenharia de sistemas e desenvolvimento de aplicações.

Possuo conhecimentos aprofundados em Estruturas de Dados, Banco de Dados, Análise de Algoritmos, Métodos Avançados de Programação, Paradigmas de Programação e Análise de Projeto de Sistemas, além de conhecimentos introdutórios em Engenharia de Software e Inteligência Artificial.

Minha experiência abrange desde o desenvolvimento de sistemas de baixo nível com C/C++ até a construção de aplicações web modernas e sistemas robustos utilizando Java, Spring Boot, C#, .NET e tecnologias do ecossistema React.

Também estou expandindo minha atuação para o desenvolvimento de jogos com a Godot Engine, já tendo desenvolvido um jogo funcional de luta em ambiente 3D. Além da programação, possuo habilidades em modelagem tridimensional, criação de assets e desenvolvimento de interfaces sofisticadas com Figma.

Tenho particular interesse na integração entre desenvolvimento de software e Inteligência Artificial, utilizando ferramentas de IA, MCPs (Model Context Protocol) e soluções de automação para otimizar fluxos de trabalho, acelerar o desenvolvimento e construir projetos mais inteligentes e produtivos.

Meu objetivo é desenvolver soluções tecnológicas eficientes, escaláveis e bem estruturadas, unindo conhecimento técnico, pensamento analítico e criatividade.
